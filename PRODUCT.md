# Product

## Register

brand

## Platform

web

## Users

Software developers, DBAs, and data engineers choosing a desktop SQL client. They already know Postgres, MySQL, or SQLite. They are tired of Electron memory cost and input lag. A visitor to this site is deciding whether to download or clone zqlcrab.

## Product Purpose

This site is the public door for **zqlcrab**, a GPU-accelerated native database desktop client written in Rust with GPUI. Success is a visitor who understands it is not a webview wrapper, finds the GitHub source and releases, and downloads the build for their machine.

## Positioning

Native 120 FPS SQL workbench — Rust and GPUI, not Electron.

## Conversion & proof

- Primary CTA: Download from GitHub Releases
- Secondary CTA: View source on GitHub
- The line a visitor remembers after 10 seconds: GPU-native database client. No webview.
- Belief ladder: it is a real desktop app → it talks to SQLite, PostgreSQL, and MySQL → editing is staged and reviewed before commit → source and binaries live on GitHub
- Proof on hand: product README, MIT OR Apache-2.0 license, GPUI/gpui-kit stack, official crab-barrel logo in `assets/logo.png`

## Brand Personality

Crustacean, GPU-native, precise. Night-harbor workstation, not a SaaS marketing kit. Copy is concrete: engines, shortcuts, staged changesets. No slogans about “unlocking data.”

## Anti-references

DBeaver splash pages, TablePlus generic feature grids, Electron-app landing templates, cream-and-terracotta AI marketing, Inter-on-navy developer clichés.

## Design Principles

- Show the workbench, don’t describe it in icon cards.
- The crab and the SQL console are the brand objects.
- Electric ocean is the only interaction color; the stage stays black.
- Chinese first, English one toggle away — the operator wrote in Chinese.
- Every outbound link that matters goes to a real GitHub URL.

## Accessibility & Inclusion

WCAG AA contrast on body and controls. Visible keyboard focus. `prefers-reduced-motion` disables the cursor blink and load motion. Language toggle is a real button, not color-only state.
